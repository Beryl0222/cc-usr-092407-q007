# 临展文创退场处置

本项目用于整理临展文创退场处置领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/exhibition_product_sunset.py`：事件种类与最小字段校验。
- `src/sunset_settlement.py`：统一清算领域服务，承担闭展锁定、渠道回报去重与冻结、互斥份额划分、职责分离、幂等落账与结算凭证。
- `data/`：用于核对资料格式的虚构事件。
- `tests/`：保证样例与领域约定保持一致，并覆盖清算链路。

## 清算链路

1. **闭展锁定**（`lock_closure`）：闭展决定固定商品版本、渠道、库存所有权与合同版本；同一场展览只能锁定一次，此后的费用与寄售分成一律以锁定的合同版本为准。
2. **渠道回报**（`ingest_report`）：直营网店、门店、仓库回报库存事实。内容相同的回报（迟到或重复）识别为同一事实，不重复入账；同标识异内容仅冻结对应渠道的对应货品，其他货品继续推进，被撤回或尚未回报的数量转入未解决差异，总量始终守恒。
3. **份额划分**（`compute_plan`）：结合在途订单、退货期、质量隔离与保留样品，把可处置量划分为退回供应商、转常设销售、捐赠、销毁的互斥份额；任何时点都不得侵占已付款订单与售后预留。
4. **批准与执行**（`approve_plan` / `run_plan`）：批准处置的人不能执行出库；退款、下架、出库步骤幂等落账，途中停机后重新处理只补齐未落账步骤。
5. **清算核对**（`statement_for_product` / `statement_for_batch`）：财务从一件商品或一个批次即可核对订单保护、库存去向、审批责任与结算凭证，未解决差异保持明确占用。

服务内维护一份只增不改的事件流水（`events()`），每个事件都满足 `validate_event` 的交换契约，可作为审计依据。
